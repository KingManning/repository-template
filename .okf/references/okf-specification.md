This bundle targets OKF version `0.1`.

The format treats each non-reserved Markdown file as a concept with YAML frontmatter and a required non-empty `type`. Standard Markdown links express relationships. `index.md` files provide progressive disclosure, and optional `log.md` files contain newest-first date-grouped history.
