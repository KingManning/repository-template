# Default Workspace

The default setup for my repositories.
Intentionally minimal, but with enough structure to support a knowledge bundle and a roadmap.
Documentation structure provided by OKF and the [documentation standards](./.okf/standards/documentation.md).
Documentation style and link validation provided by the [Scripts README](./scripts/README.md) and the [PyMarkdown configuration](./.pymarkdown.json).

## What this repo contains

- [`.github/`](./.github) - pull request template and Copilot instructions.
- [`.okf/`](./.okf) - repository documentation hub.
- [Scripts README](./scripts/README.md) - commands to check and fix Markdown style and internal links.
- [`tests/`](./tests) - focused tests for repository tooling.
- [`AGENTS.md`](./AGENTS.md) - repository-wide agent instructions.
- [`.pymarkdown.json`](./.pymarkdown.json), [`requirements.in`](./requirements.in),
  and [`requirements.txt`](./requirements.txt) - Markdown lint rules and Python
  tooling dependencies.
